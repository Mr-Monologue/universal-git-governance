# 候选发行审批清单

未来审批用途，本次仅准备和本地提交，不执行以下发布动作。

- [ ] 确认准确发布范围、提交、干净工作区及敏感信息检查。
- [ ] 接受 C01 摘录来源、C02 损坏历史和 C04 范围限制，审阅原生证据。
- [ ] 分别批准两个 Skill 的版本/状态，批准仓库聚合版本及 Manifest。
- [ ] 完成实际支持平台的全量回归、权限相关测试、远端 CI。
- [ ] 明确 Codex 支持范围；Cursor/Copilot 未测不列原生通过。
- [ ] 单独授权 Task 012 集成到 develop；本次没有执行。
- [ ] 单独授权候选进入固定 release，必要时经授权建立本地跟踪分支。
- [ ] 分别授权 RC Tag/推送，记录候选提交与不可变包哈希。
- [ ] 验证候选包安装、校验、升级、移除、旧版兼容和备份恢复。
- [ ] 候选通过后取得当次 release → main 晋升授权。
- [ ] 在实际 main 发布提交上按授权创建正式 Annotated Tag，中文说明范围和限制。
- [ ] 分别授权 Push、Tag 推送、公开 Release 与制品上传。
- [ ] 发布前消除 Manifest 占位，核对最终包与已验证包一致。
