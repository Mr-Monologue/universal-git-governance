# 原始 C 规范审阅与现代化改动（v0.1）

本次修订源于用户提供的《MISRA C和C语言编程规范check list.md》，不是替代用户原始风格偏好的最终决定。原文件可以继续作为历史输入保留；**新规范建议作为唯一的 Agent 规则正文**。

## 保留的基线

- 遵循指定的 C 标准、重视有损类型转换和初始化。
- 函数单一职责、公开头文件、模块化设计、减少不必要的全局可变状态。
- 数组和指针安全、检查可失败调用、可理解的错误处理。
- 统一格式、头文件 guard、宏与枚举命名、防御性编程。
- 通过静态分析/测试降低未定义行为和缓冲区错误。

## 明确修正的规则

| 原文表达 | 本版处理 |
| --- | --- |
| 4 空格缩进、使用 Tab | 选择 4 空格，不使用 Tab；由 clang-format 管理 |
| 函数返回值必须检查 | 只强制检查有错误语义、必须处理的结果 |
| 任何指针使用前必须判空 | 按可信边界、契约和指针来源检查 |
| 使用 `strncpy` 即为安全复制 | 明确终止符/截断要求，不能默认安全 |
| `goto` 一律禁止 | 允许受控 `goto cleanup` 处理资源释放 |
| 浮点应尽量禁用 | 按 FPU、算法精度、时限决定 |
| 指针使用 `p_`、函数指针 `pf_` | 设为项目级旧风格选项，不通用强制 |
| 全部枚举变量 `_T`、类型 `_t` | 类型命名统一化，但跨平台需注意 `_t` 约束 |
| `default` 无条件必须存在 | 完整处理非法值，同时保留编译器枚举遗漏告警 |
| 失败必须写日志 | 改为可观测错误机制，兼容实时场景 |
| 每文件都填版本、作者、日期、历史表 | Git 管历史、实际许可证与身份必须真实 |
| 关键函数有注释 | 升级为 **Doxygen 强制 API 契约** |

## 本版新增（原文件不完整覆盖）
